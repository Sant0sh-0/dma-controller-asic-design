High-speed DMA controller design for ASIC applications enabling efficient memory and peripheral data transfer with minimal CPU intervention.

# DMA Controller ASIC Design
## 📌 Overview
This project presents the design and verification of a Direct Memory Access (DMA) controller for high-speed data transfer without CPU intervention.

## ⚙️ Features
- Memory-to-Memory transfer
- Memory-to-Peripheral transfer
- Auto address increment
- Interrupt generation
- Low power ASIC-oriented design

## 🏗️ Architecture
Includes:
- Control Unit
- Address Generation Unit
- Data Path
- Mode Selection Logic

## 🔄 Working
1. CPU initializes DMA
2. DMA requests bus
3. Data transfer begins
4. Address auto-increments
5. Interrupt generated on completion
